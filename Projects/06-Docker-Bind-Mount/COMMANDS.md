# 🐳 Docker Bind Mounts - Commands Reference

This document contains all Docker commands used in Project 06.

---

# 1. Build Docker Image

```bash
docker build -t todo .
```

Builds a Docker image named **todo** using the Dockerfile in the current directory.

---

# 2. View Docker Images

```bash
docker images
```

Displays all Docker images stored on the local machine.

---

# 3. Run Container (Without Bind Mount)

```bash
docker run -d --name todo-app -p 8080:80 todo
```

Creates and starts a container from the **todo** image.

Options:

- `-d` → Run in detached mode.
- `--name` → Assign a custom container name.
- `-p` → Map host port to container port.

---

# 4. View Running Containers

```bash
docker ps
```

Displays all running containers.

---

# 5. View All Containers

```bash
docker ps -a
```

Displays both running and stopped containers.

---

# 6. Stop Container

```bash
docker stop todo-app
```

Stops the running container.

---

# 7. Remove Container

```bash
docker rm todo-app
```

Deletes the stopped container.

Force remove

```bash
docker rm -f todo-app
```

---

# 8. Run Container Using Bind Mount (Windows CMD)

```bash
docker run -d --name todo-app -p 8080:80 -v "%cd%":/usr/share/nginx/html nginx:alpine
```

Mounts the current project folder inside the Nginx container.

Any changes made locally are immediately reflected in the browser.

---

# 9. Run Container Using Bind Mount (PowerShell)

```powershell
docker run -d --name todo-app -p 8080:80 -v "${PWD}:/usr/share/nginx/html" nginx:alpine
```

PowerShell equivalent of the previous command.

---

# 10. View Container Logs

```bash
docker logs todo-app
```

Displays logs generated by the running container.

---

# 11. Open a Shell Inside the Container

```bash
docker exec -it todo-app sh
```

Starts an interactive shell inside the container.

Useful for debugging.

---

# 12. Inspect Container Details

```bash
docker inspect todo-app
```

Shows detailed information about the container, including mounts, networking, and configuration.

---

# 13. Remove Unused Docker Resources

```bash
docker system prune
```

Removes stopped containers, unused networks, and dangling images.

---

# 14. Remove Everything (Use Carefully)

```bash
docker system prune -a
```

Removes all unused Docker resources, including images not used by any container.

---

# Command Summary

| Command | Purpose |
|----------|---------|
| docker build | Build Docker image |
| docker images | List Docker images |
| docker run | Create and start container |
| docker ps | Running containers |
| docker ps -a | All containers |
| docker stop | Stop container |
| docker rm | Remove container |
| docker logs | View logs |
| docker exec | Open container shell |
| docker inspect | Inspect container |
| docker system prune | Clean Docker resources |
